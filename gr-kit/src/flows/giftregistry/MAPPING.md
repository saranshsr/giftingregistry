## Haptics (noon nano haptics system, web vocabulary)

`haptics.ts` is the skill's `haptics.web.js` + `platform.js`, typed: native WKWebView bridge, else the iOS Safari switch burst, else Android `navigator.vibrate`; one app-wide switch (`setHapticsEnabled`); `prepareHaptics()` on Account, My Lists and the steps installs the flow's tap listener (scoped to `giftregistry/*` screens; a handler that played its own wins, `data-haptic="off"` silences).

| Moment | Haptic | Web recipe | Where |
|---|---|---|---|
| Continue / Create / explainer Continue / Search gifts (touch-down) | press | native heavy 1.0 · Android 110 ms · iOS Safari 5 ticks | `components/NanoButton` (StepsScreen, CreateSheet, RegistryScreen) |
| the same buttons (touch-up, or a cancelled press) | release | native light 0.4 · Android 60 ms · **iOS Safari silent**: the switch trick has one fixed-strength tick, so a softer release can't be played there; it only marks the tap as handled | `components/NanoButton` |
| Account Gift Registries card, My Lists registry tile, Create sheet registry card | lift | light, 4 ticks | GiftRegistriesCard, RegistryStrip, CreateSheet |
| + Create, Pick from calendar | tap | light | ListsScreen, StepsScreen chip |
| Back / X, address card edit (opens the sheet), leave at door, address picked, field focus (listener) | lightTap | selection, 3 ticks | StepsScreen, RegistryScreen back, AddressSheet |
| Occasion picked, a date picked | selectionTick | selection | StepsScreen |
| Numpad digit / delete | keyTick | selection | StepsScreen Numpad |
| Sheet swiped away / let go short | swipe / aborted | light / selection | index.ts `onDragRelease` (kit sheet option) |
| Invalid CTA (a tap on the disabled NanoButton, with the shake) | failure | error, 11 ticks | StepsScreen `onDisabledClick` |
| Registry page lands | settle, success +160 ms | settle / success | RegistryScreen (300 ms after mount) |
| Step hero lands (frame 21, `lottie_cues.py`) | cue light | light | HeroLottie `cue`, only after a tapped step change < 1 s ago, skipped if late or < 150 ms after the last haptic |
| Intros, page loads, theme swaps, Continue waking after a date pick | none | | rule 7 |
